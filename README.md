# Training-Planner
**Автор:** Белан Николь
Особенности:
Добавление тренировок с датой, типом и длительностью
Просмотр списка тренировок в таблице
Фильтрация по дате и типу
Сохранение данных в JSON-файл
Загрузка данных из файла
Очистка фильтров и просмотр полного списка
Использование:
Введите дату, тип тренировки и длительность
Нажмите "Добавить тренировку"
Для сохранения данных — "Сохранить"
Для загрузки — "Загрузить"
Чтобы фильтровать — используйте кнопки "Фильтр по типу" или "Фильтр по дате" и вводите параметры
Для сброса фильтров — "Сброс фильтра"
Запуск:
python main.py
